۳.۶ جدول هر وعده

```html
<table id="cphMain_grdReservation{Breakfast|Lunch|Dinner}">
  <tr class="HeaderStyle">…</tr>
  <tr class="aspNetDisabled">…</tr>   <!-- ردیف قفل‌شده -->
  <tr style="background-color:#EAFAEA;">…</tr> <!-- ردیف رزرو‌شده -->
  <tr>…</tr>                          <!-- ردیف باز، رزرو‌نشده -->
</table>
```

ستون‌ها (به ترتیب <td>)

اندیس محتوا نام فیلد
۰ Checkbox ctl00$cphMain$grdReservation{Meal}$ctl{NN}$chkReserve
۱ نام روز شنبه 1405/08/16
۲ Select سلف …$ctl{NN}$drpSelf
۳ Select غذا …$ctl{NN}$drpFood
۴ Select تعداد …$ctl{NN}$drpFoodCount
۵ span کالری …$lblFoodCalorie_N
۶ span مبلغ …$lblBuyAmount_N
۷ img وضعیت …$imgStaus_N

NN بین 02 و 08 است (۷ روز؛ 01 مال header checkbox است).

معانی مقادیر

· checkbox:
  · موجود و checked → روز انتخاب/رزرو شده
  · موجود و unchecked → امکان انتخاب دارد ولی رزرو نیست
  · غایب (disabled) → قفل است (پایان مهلت یا وعده منتشر نشده). در بدنهٔ POST برای روزهای disabled باید drpSelf=-1, drpFood=-1, drpFoodCount=0 ارسال شود (همانطور که مرورگر از <option selected> می‌خواند).
· drpSelf: 1 = پردیس (تنها گزینه در دانشگاه بیرجند)
· drpFood: -1 = هیچ‌کدام؛ در غیر این صورت ID غذا (پایین‌تر لیست)
· drpFoodCount: 0 یا 1
· imgStaus.title — نمونه‌ها:
  · غیرفعال → قفل
  · رزرو شده → رزرو فعال
  · رزرو شده، خورده نشده، غیرفعال → رزرو شده اما دیگر قابل تغییر نیست (وسط هفته)
  · خورده شده - دستگاه - HH:MM:SS → تحویل داده شده
· <option>های drpFood — هر value یک شناسه غذا و متن شامل نام غذا، اجزا و قیمت است.

۳.۷ برچسب هفته

<label id="cphMain_lblWeekDate">1405/08/16  الی  1405/08/22</label> — برای نمایش هفتهٔ جاری بعد از هر آپدیت.

۳.۸ برچسب اعتبار

<label id="cphMain_lblCreditValue">اعتبار شما: 1,410,000- ریال</label> — علامت منفی قبل از عدد در نمایش فارسی؛ مثلاً -۱,۴۱۰,۰۰۰ یعنی بدهی ۱٬۴۱۰٬۰۰۰ ریال. مقایسهٔ این مقدار قبل/بعد از هر عملیات، مبلغ تراکنش را می‌دهد.

۴. مکانیزم Delta (کلید ارتباط با سرور)

همهٔ درخواست‌های صفحهٔ رزرو (پیمایش هفته + ذخیره) با یک الگوی یکسان انجام می‌شوند.

۴.۱ هدرها

```
POST /Reservation/Reservation.aspx
Accept: */*
Content-Type: application/x-www-form-urlencoded; charset=UTF-8
Origin: https://jeton.bums.ac.ir
Referer: https://jeton.bums.ac.ir/Reservation/Reservation.aspx
X-MicrosoftAjax: Delta=true
X-Requested-With: XMLHttpRequest
```

۴.۲ بدنهٔ POST — الگوی کلی

باید کل حالت صفحه ارسال شود. به ترتیب:

1. ctl00$ScriptManager = ctl00$UpdatePanel1|<triggerID>
   · برای پیمایش هفته: ctl00$UpdatePanel1|ctl00$cphMain$imgbtnNextWeek
   · برای ذخیرهٔ ناهار: ctl00$UpdatePanel1|ctl00$cphMain$btnSaveLunch
2. ctl00$cphMain$hdnSelectedTab = css3-tabstrip-0-1 (مثلاً برای ناهار)
3. برای هر وعده × هر ۷ روز:
   · اگر روز قفل است: drpSelf=-1&drpFood=-1&drpFoodCount=0 (بدون chkReserve)
   · اگر روز باز است:
     · chkReserve=on فقط اگر checked باشد (اگر unchecked، اصلاً ارسال نمی‌شود)
     · drpSelf, drpFood, drpFoodCount (همیشه ارسال می‌شوند)
4. css3-tabstrip-0=on
5. __EVENTTARGET=
6. __EVENTARGUMENT=
7. __LASTFOCUS=
8. __VIEWSTATE=<newest from last response>
9. __VIEWSTATEGENERATOR=3ED98A75
10. __VIEWSTATEENCRYPTED=
11. __ASYNCPOST=true
12. دکمهٔ trigger:
    · هفته: ctl00$cphMain$imgbtnNextWeek.x=22&ctl00$cphMain$imgbtnNextWeek.y=30
    · ذخیره: ctl00$cphMain$btnSaveLunch=<urlencoded label>

نکتهٔ حیاتی: اگر chkReserve را برای روزی که قبلاً رزرو بود حذف کنید، آن روز لغو می‌شود. اگر اضافه کنید، رزرو می‌شود.

۴.۳ پاسخ سرور (Delta)

Content-Type: text/plain; charset=utf-8

ساختار (تکرارشونده، هر بلوک <len>|<type>|<id>|<content>|):

```
1|#||4|<len>|updatePanel|UpdatePanel1|<HTML of tabstrip>|
|<len>|hiddenField|__EVENTTARGET||0|hiddenField|__EVENTARGUMENT||0|hiddenField|__LASTFOCUS||
|<len>|hiddenField|__VIEWSTATE|<new value>|8|hiddenField|__VIEWSTATEGENERATOR|3ED98A75|
|0|hiddenField|__VIEWSTATEENCRYPTED||
|0|asyncPostBackControlIDs|||0|postBackControlIDs||
|<len>|updatePanelIDs||tctl00$UpdatePanel1,UpdatePanel1|0|childUpdatePanelIDs||
|<len>|panelsToRefreshIDs||ctl00$UpdatePanel1,UpdatePanel1|3|asyncPostBackTimeout||400|
|18|formAction||./Reservation.aspx|
|<len>|scriptStartupBlock|ScriptContentNoTags|<JS>|
```

نکات پارس:

· len تعداد بایت بخش content است، نه تعداد کاراکتر. باید روی bytes پارس کنید.
· updatePanel|UpdatePanel1 = HTML جدید کل ناحیهٔ تب (همهٔ جداول). این را جایگزین HTML قبلی می‌کنید و از آن مقادیر جدید checkbox/dropdown می‌خوانید.
· hiddenField|__VIEWSTATE = مقدار جدید viewstate. حتماً جایگزین قبلی شود.
· scriptStartupBlock = پیام موفقیت/خطا (پایین‌تر).

۴.۴ پیام‌های scriptStartupBlock

```js
toastify('success', ' رزرو غذا برای 1 روز با موفقیت انجام شد؛ ',
         'عملیات موفق!', 'toast-bottom-right', 'true');
```

```js
toastify('success', ' لغو رزرو غذا برای 1 روز با موفقیت انجام شد؛ ',
         'عملیات موفق!', 'toast-bottom-right', 'true');
```

الگوی استخراج: r"toastify\('(\w+)',\s*'([^']*)'" — و (\d+)\s*روز برای تعداد روز. اگر error بود، پیام خطا برمی‌گردد.

۴.۵ رفتار مشاهده‌شده در HAR

درخواست trigger نتیجه تغییر اعتبار
۱ imgbtnNextWeek هفته ۱۴۰۵/۰۸/۱۶ تا ۲۲ برگشت بدون تغییر
۲ btnSaveLunch لغو رزرو غذا برای 1 روز -1,410,000 → -1,230,000 (افزایش ۱۸۰٬۰۰۰)
۳ btnSaveLunch رزرو غذا برای 1 روز -1,230,000 → -1,410,000 (کاهش ۱۸۰٬۰۰۰)

تفسیر: اختلاف بین درخواست ۲ و ۳ صرفاً در حالت chkReserve بود. تفاوت این بود که ctl06$chkReserve (چهارشنبه) در هیچ‌کدام ارسال نشد اما تیک ctl05$chkReserve (سه‌شنبه) در درخواست ۳ وجود داشت... این دقیقاً منطق «هرچه چک‌باکس علامت‌دار است را رزرو کن، هرچه بی‌علامت است را آزاد کن» را اثبات می‌کند. برای ساختن کلاینت، فقط باید ست چک‌باکس‌ها را روی خواستهٔ خود تنظیم کنید.

۷. نکات عملی و دام‌ها

1. <len> بایتی است؛ هرگز با len(str) پارس نکنید. از encode('utf-8') و ایندکس bytes استفاده کنید.
2. __VIEWSTATE جدید را حتماً از پاسخ بردارید؛ ارسال مقدار قبلی منجر به خطای «viewstate invalid» (صفحهٔ خطای ASP.NET یا پاسخ خالی Delta) می‌شود.
3. کلید عمومی را هاردکد نکنید — از publicKeytxt صفحهٔ ورود بخوانید. اگر سرور کلید را عوض کند، اسکریپت خودکار سازگار می‌شود.
4. chkReserve را برای روزهای disabled اصلاً نفرستید. برای روزهای enabled اما unchecked هم نفرستید (نه با مقدار خالی، بلکه حذف کامل کلید).
5. drpSelf, drpFood, drpFoodCount را برای همهٔ روزها بفرستید — حتی برای روزهای قفل، با مقدار -1/-1/0 (که در HTML خودشان selected هستند).
6. ctl00$cphMain$hdnSelectedTab و css3-tabstrip-0=on و ScriptManager باید با هم برای همان تب باشند.
7. btnSave{Meal} باید در بدنهٔ POST با URL-encoded مقدارش بیاید (مثلاً ذخیره ناهار). فقط ScriptManager کافی نیست — سرور از این فیلد تشخیص می‌دهد دکمه فشار داده شده.
8. imgbtn{Last|Next|Current}Week برای فشرده‌شدن به .x/.y نیاز دارد (مثلاً ۲۲/۳۰).
9. جلسه بعد از حدود ۲۰ دقیقه بی‌کاری منقضی می‌شود (ASP.NET default). اگر پاسخ Delta نداشت updatePanel، احتمالاً ۳۰۲ به /Login.aspx رخ داده است.
10. مرورگر httpx/requests باید Accept-Language, User-Agent استاندارد بدهد. Referer و Origin را در هر POST ست کنید.
11. Content-Type پاسخ text/plain; charset=utf-8 است (نه text/html) — کتابخانه‌های HTTP باید متن را دست‌نخورده برگردانند.
12. تشخیص موفقیت یک عملیات صرفاً از scriptStartupBlock ممکن است؛ گاهی (مثلاً عملیات بدون تغییر) هیچ toast نمی‌آید. تغییر cphMain_lblCreditValue و وضعیت chkReserveها در updatePanel معیار تکمیلی‌اند.
13. __LASTFOCUS در برخی درخواست‌ها وجود دارد؛ خالی فرستادنش خطا نمی‌دهد.
14. __EVENTVALIDATION در این اپلیکیشن استفاده نمی‌شود (در فایل‌های نمونه دیده نشد). فقط ViewState + AntiXsrf کوکی کافی است.
15. محدودیت نرخ: در HAR فاصله‌های بین درخواست‌ها ~۱ ثانیه بود. توصیه: ۲-۳ ثانیه بین درخواست‌ها، و هرگز دو ذخیرهٔ همزمان برای یک تب نفرستید.
16. کپچا GIF با image/gif — اگر پاسخ text/html بود یعنی نشست/کوکی درست منتقل نشده است.
17. بعد از هر ذخیره، حالت داخلی را از پاسخ Delta بازسازی کنید — نه با اعمال تغییر خودتان. برخی فیلدها (مثلاً imgStaus_N) توسط سرور ست می‌شوند.

۸.۱ پارس Delta

```python
def parse_delta(raw: bytes):
    out = {"panels": {}, "hidden": {}, "script": ""}
    i = 0
    while i < len(raw):
        p1 = raw.find(b"|", i)
        if p1 == -1: break
        try: n = int(raw[i:p1])
        except ValueError: break
        p2 = raw.find(b"|", p1 + 1)
        p3 = raw.find(b"|", p2 + 1)
        if p2 == -1 or p3 == -1: break
        typ = raw[p1+1:p2].decode("utf-8", "replace")
        pid = raw[p2+1:p3].decode("utf-8", "replace")
        start = p3 + 1
        content = raw[start:start+n].decode("utf-8", "replace")
        i = start + n + 1
        if typ == "updatePanel":  out["panels"][pid] = content
        elif typ == "hiddenField": out["hidden"][pid] = content
        elif typ == "scriptStartupBlock": out["script"] += content + "\n"
    return out
```

import re
def extract_toast(js):
    m = re.search(r"toastify\('(\w+)',\s*'([^']*)'", js)
    if not m: return None
    kind, msg = m.group(1), m.group(2).strip()
    days = re.search(r"(\d+)\s*روز", msg)
    return kind, msg, (int(days.group(1)) if days else None)

from bs4 import BeautifulSoup
def parse_meal(soup, meal):
    t = soup.select_one(f"table#cphMain_grdReservation{meal}")
    rows = []
    for tr in t.select("tr"):
        if "HeaderStyle" in (tr.get("class") or []): continue
        tds = tr.find_all("td")
        if len(tds) < 8: continue
        chk = tds[0].find("input", {"type": "checkbox"})
        name = chk["name"]                      # ...$ctl02$chkReserve
        ctl  = re.search(r"ctl(\d+)", name).group(0)   # ctl02
        rows.append({
            "day":     tds[1].get_text(strip=True),
            "ctl":     ctl,
            "locked":  "disabled" in chk.attrs,
            "reserved": "checked" in chk.attrs,
            "self":    int(tds[2].find("select").find("option", selected=True)["value"]),
            "food":    int(tds[3].find("select").find("option", selected=True)["value"]),
            "count":   int(tds[4].find("select").find("option", selected=True)["value"]),
            "status":  tds[7].find("img")["title"] if tds[7].find("img") else "",
        })
    return rows

def flat_grid_fields(state):
    body = {}
    for meal, rows in state["grids"].items():
        for r in rows:
            base = f"ctl00$cphMain$grdReservation{meal}${r['ctl']}$"
            body[base + "drpSelf"]      = str(r["self"])
            body[base + "drpFood"]      = str(r["food"])
            body[base + "drpFoodCount"] = str(r["count"])
            if not r["locked"] and r["reserved"]:
                body[base + "chkReserve"] = "on"
    return body
