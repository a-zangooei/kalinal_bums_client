# 📚 دانشنامه و مستندات فنی پروژه کالینان (Kalinan Documentation)

به دانشنامه و مستندات جامع فنی کلاینت اندرویدی **کالینان (Kalinan)** خوش آمدید.  
این پروژه یک کلاینت غیررسمی، مدرن و متن‌باز اندروید بر پایه **Jetpack Compose** برای سامانه رزرواسیون غذای دانشجویی دانشگاه علوم پزشکی بیرجند ([https://jeton.bums.ac.ir](https://jeton.bums.ac.ir)) است.

این مستندات به گونه‌ای ساختاریافته، ماژولار و استاندارد نگارش شده است تا هر توسعه‌دهنده جدید، مهندس نرم‌افزار، شخص فورک‌کننده یا موتورهای پیشرفته هوش مصنوعی بتوانند کل ساختار، معماری و جزئیات پروتکل مهندسی معکوس‌شده وب‌فرم‌های ASP.NET را درک کرده و توسعه دهند.

## 💡 اصول کلیدی طراحی در این پروژه

1. **ارتباط مستقیم و غیرواسطه‌ای (Zero-Proxy):** هیچ سرور میانی یا شخص ثالثی بین گوشی کاربر و سرور دانشگاه وجود ندارد؛ تمامی ارتباطات مستقیماً با آدرس `jeton.bums.ac.ir` انجام می‌شود.
2. **پشتیبانی کامل از تمامی وعده‌ها:** بر خلاف کلاینت‌های محدود، امکان مشاهده، رزرو و لغو برای هر سه وعده **صبحانه**، **ناهار** و **شام** پیاده‌سازی شده است.
3. **مقاومت در برابر خطاهای زیرساختی شبکه (Network Resilience):** مجهز به مکانیزم هوشمند رفع خودکار خطای زنجیره ناقص گواهی SSL، مدیریت خطاهای ۵۰۰ داخلی سرور، و کشف بلادرنگ انقضای نشست (Session Expiration).
4. **تست‌پذیری بالا (Mock & Fixture Driven):** تمام رفتارهای حیاتی نرم‌افزار بدون ارسال درخواست به سرور واقعی و بدون رزرو یا لغو ناخواسته غذای واقعی، توسط MockWebServer و فایل‌های ضبط‌شده ترافیک تست می‌شوند.
