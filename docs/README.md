# 📚 دانشنامه و مستندات فنی پروژه کالینان (Kalinan Documentation)

به دانشنامه و مستندات جامع فنی کلاینت اندرویدی **کالینان (Kalinan)** خوش آمدید.  
این پروژه یک کلاینت غیررسمی و متن‌باز اندروید بر پایه **Jetpack Compose** برای سامانه رزرواسیون غذای دانشجویی دانشگاه علوم پزشکی بیرجند ([https://jeton.bums.ac.ir](https://jeton.bums.ac.ir)) است.

این مستندات به گونه‌ای ساختاریافته، ماژولار و استاندارد نگارش شده است تا هر توسعه‌دهنده جدید، مهندس نرم‌افزار یا شخص فورک‌کننده بتواند کل ساختار، معماری، واقعیت فعلی لایه انتقال و جزئیات پروتکل مهندسی معکوس‌شده وب‌فرم‌های ASP.NET را درک کرده و توسعه دهد.

## 💡 اصول و وضعیت فعلی طراحی در این پروژه

1. **ارتباط مستقیم و غیرواسطه‌ای (Zero-Proxy):** هیچ سرور میانی یا شخص ثالثی توسط برنامه بین گوشی کاربر و سرور دانشگاه وجود ندارد؛ تمامی ارتباطات مستقیماً با آدرس `jeton.bums.ac.ir` برقرار می‌شود.
2. **پشتیبانی کامل از تمامی وعده‌ها و ناوبری هفتگی:** امکان مشاهده، رزرو و لغو برای هر سه وعده **صبحانه**، **ناهار** و **شام** و جابه‌جایی بین هفته‌های قبل و بعد پیاده‌سازی شده است.
3. **مدیریت خطاهای زیرساختی و وضعیت موقت SSL:** کلاینت خطاهای ۵۰۰ داخلی سرور و انقضای نشست (Session Expiration) را تشخیص می‌دهد. **توضیح شفاف:** تا زمان پیاده‌سازی فاز بعدی SSL (همراه‌سازی ریشه `Certum Trusted Root CA`)، خطاهای `SSLException` منجر به ورود کلاینت به حالت موقت `fallbackClient` بدون اعتبارسنجی گواهی می‌شوند که در [مستندات SSL](./03-security-and-ssl/ssl-certificate-chain.md) تشریح شده است.
4. **تست‌پذیری بالا (Mock & Fixture Driven):** تمام رفتارهای حیاتی نرم‌افزار بدون ارسال درخواست به سرور واقعی و بدون رزرو یا لغو ناخواسته غذای واقعی، توسط MockWebServer و فایل‌های ضبط‌شده ترافیک تست می‌شوند.
