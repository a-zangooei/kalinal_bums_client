# 🌐 مهندسی معکوس پروتکل ASP.NET سامانه کالینان (ASP.NET Web Forms Protocol)

سامانه رزرواسیون غذای دانشجویی دانشگاه علوم پزشکی بیرجند ([https://jeton.bums.ac.ir](https://jeton.bums.ac.ir)) بر پایه فناوری قدیمی اما گسترده **ASP.NET Web Forms** پیاده‌سازی شده است. این مستند به تحلیل دقیق چرخه عمر درخواست‌ها، احراز هویت و نشست‌ها می‌پردازد.

---

## ۱. چرخه کامل ورود و احراز هویت (Login Flow)

```
[کلاینت کالینان]                                               [سرور دانشگاه]
       │                                                               │
       │ 1. GET /Login.aspx                                            │
       ├──────────────────────────────────────────────────────────────>│
       │                                                               │
       │ 2. 200 OK (HTML + Set-Cookie: ASP.NET_SessionId=...)          │
       │    [استخراج: __VIEWSTATE, __VIEWSTATEGENERATOR, publicKeytxt]  │
       │<──────────────────────────────────────────────────────────────┤
       │                                                               │
       │ 3. GET /UserControls/Captcha.ashx?t={timestamp}               │
       │    [همراه با کوکی ASP.NET_SessionId جاری]                     │
       ├──────────────────────────────────────────────────────────────>│
       │                                                               │
       │ 4. 200 OK (تصویر باینری PNG/JPEG کپچا)                        │
       │<──────────────────────────────────────────────────────────────┤
       │                                                               │
       │ 5. POST /Login.aspx (فرم حاوی مقادیر رمزنگاری‌شده و کپچا)     │
       ├──────────────────────────────────────────────────────────────>│
       │                                                               │
       │ 6. 302 Redirect یا بارگذاری صفحه /Master/Default.aspx         │
       │<──────────────────────────────────────────────────────────────┤
```

## ۲. فیلدهای کلیدی فرم صفحه ورود (`Login.aspx`)

برای ارسال درخواست معتبر ورود، فیلدهای زیر باید در فرم POST گنجانده شوند:

| نام فیلد (Key) | منبع مقدار | نقش در سیستم |
|---|---|---|
| `__VIEWSTATE` | تگ `<input name="__VIEWSTATE">` در HTML ورودی | وضعیت کنونی کنترل‌های صفحه سرور |
| `__VIEWSTATEGENERATOR` | تگ `<input name="__VIEWSTATEGENERATOR">` (پیش‌فرض: `C2EE9ABB`) | هش شناسایی فرم در IIS |
| `__VIEWSTATEENCRYPTED` | رشته خالی `""` | نشانگر فیلد رمزنگاری ویواستیت |
| `publicKeytxt` | محتوای عنصر `#publicKeytxt` | کلید عمومی RSA سرور (با فرمت PEM) |
| `txtUsernamePlain` | رشته خالی `""` | فیلد نمایشی کلاینت (نباید مقدار داشته باشد) |
| `txtPasswordPlain` | رشته خالی `""` | فیلد نمایشی کلاینت (نباید مقدار داشته باشد) |
| `txtUsername` | رشته رمزنگاری‌شده با RSA (Base64) | شماره دانشجویی رمزگذاری‌شده با کلید عمومی |
| `txtPassword` | رشته رمزنگاری‌شده با RSA (Base64) | گذرواژه (کد ملی) رمزگذاری‌شده با کلید عمومی |
| `txtCaptcha` | رشته ۴ رقمی تایپ‌شده توسط کاربر | کد امنیتی اعتبارسنجی کپچا |
| `btnLogin` | عبارت `"ورود سمت سرور "` (همراه با فاصله در انتها) | شبیه‌سازی کلیک دکمه Submit در ASP.NET |
| `CanSaveloginPasstxt` | مقدار `"True"` | پرچم ذخیره ورود امن |
| `loginSecurtxt` | مقدار `"True"` | پرچم فعال بودن رمزنگاری امن در کلاینت |

## ۳. مدیریت کوکی‌ها و نشست کاری (Session Management)

- **اهمیت کوکی `ASP.NET_SessionId`:**  
  سامانه دانشگاه تصویر کپچا را بر اساس سشن جاری تولید و در حافظه سرور نگه می‌دارد. اگر درخواست دریافت تصویر کپچا بدون کوکی سشن ارسال شود یا کوکی جدیدی ایجاد کند، کدی که کاربر می‌بیند با کدی که سرور در نشست لاگین منتظر آن است متفاوت خواهد بود و خطای **«کد امنیتی اشتباه است»** صادر می‌شود.
- **راهکار پیاده‌سازی‌شده در `CullinanCookieJar`:**  
  یک کوکی‌جار اشتراکی در حافظه رم، تمامی کوکی‌های پاسخ صفحه `Login.aspx` را ذخیره کرده و به صورت خودکار در درخواست‌های بعدی به `Captcha.ashx` و `Reservation.aspx` ضمیمه می‌کند.
- **پاکسازی پس از خروج:**  
  به محض خروج کاربر یا بروز خطای انقضای نشست، متد `cookieJar.clear()` فراخوانی می‌شود تا کلیه نشست‌های پیشین پاک شوند.
