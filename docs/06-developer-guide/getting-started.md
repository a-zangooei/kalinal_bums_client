# 🚀 راهنمای شروع سریع و راه‌اندازی محلی (Getting Started Guide)

این راهنما مراحل گام‌به‌گام برای کلون کردن مخزن، راه‌اندازی در محیط توسعه (Android Studio)، کامپایل و اجرای اپلیکیشن کالینان را توضیح می‌دهد.

---

## ۱. پیش‌نیازها

- **سیستم‌عامل:** ویندوز، لینوکس یا مک‌اواس.
- **JDK:** نسخه **JDK 21** (توزیع پیشنهادی: Eclipse Temurin یا OpenJDK 21).
- **محیط توسعه:** Android Studio (نسخه Koala / Ladybug یا جدیدتر).
- **اندروید SDK:** حداقل `minSdk = 24` (اندروید ۷.۰ به بالا) و `targetSdk = 36`.

---

## ۲. دریافت مخزن و کامپایل اولیه

```bash
# ۱. کلون کردن مخزن
git clone https://github.com/a-zangooei/kalinan_bums_client.git
cd kalinan_bums_client

# ۲. ایجاد فایل محیطی اولیه
touch .env

# ۳. کامپایل اپلیکیشن و ساخت APK دیباگ
./gradlew assembleDebug
```

فایل APK تولید شده در مسیر زیر قرار می‌گیرد:
`app/build/outputs/apk/debug/app-debug.apk`

---

## ۳. تنظیمات بهینه سخت‌افزاری در `gradle.properties`

اگر روی سیستم شخصی با پردازنده سبک (مانند پردازنده‌های ۲ هسته‌ای Celeron یا رم ۸ گیگابایت) کار می‌کنید:
- تنظیمات سقف رم در `gradle.properties` روی `-Xmx2048m` و `org.gradle.workers.max=2` قرار داده شده تا سیستم فریز نشود.
- در گیت‌هاب اکشن، از طریق متغیر محیطی `GRADLE_OPTS` به صورت خودکار از رم ۴ گیگابایت و ۴ ورکر استفاده می‌شود.

---

## ۴. باز کردن پروژه در Android Studio

1. نرم‌افزار Android Studio را باز کنید.
2. گزینه **Open** را انتخاب کرده و پوشه ریشه پروژه را انتخاب نمایید.
3. اجازه دهید فرایند Gradle Sync به اتمام برسد.
4. امولاتور یا گوشی اندرویدی خود را متصل کرده و دکمه سبز رنگ **Run** را بزنید.
