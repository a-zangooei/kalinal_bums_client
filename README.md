## 📌 درباره پروژه

سامانه رسمی تغذیه و رزرو غذای دانشگاه علوم پزشکی بیرجند (`jeton.bums.ac.ir`) مبتنی بر سیستم کالینان و فناوری وب‌فرم است که کار با آن روی مرورگر تلفن همراه با دشواری‌هایی چون لزوم زوم مداوم، ورودهای پی‌درپی و فرآیند زمان‌بر رزرو و لغو همراه است.

**کالینان** یک کلاینت غیررسمی، مستقل و **۱۰۰٪ متن‌باز (Open Source)** برای اندروید است که واسط کاربری را به تجربه‌ای مدرن، روان و منطبق بر **Material Design 3** تبدیل کرده است تا دانشجویان، کادر درمان و اساتید محترم بتوانند در کمتر از چند ثانیه وضعیت وعده‌ها را مشاهده، رزرو یا لغو نمایند.

> ⚠️ **سلب مسئولیت:** این اپلیکیشن به صورت داوطلبانه، غیرانتفاعی و مستقل توسط جامعه دانشجویی توسعه یافته و هیچ‌گونه وابستگی رسمی به مدیریت فناوری اطلاعات دانشگاه علوم پزشکی بیرجند ندارد.

## 🔒 امنیت و حفظ حریم خصوصی (تعهد شفاف)

بزرگ‌ترین دغدغه در استفاده از نرم‌افزارهای غیررسمی، **امنیت اطلاعات ورود** و **جلوگیری از فیشینگ یا سوءاستفاده** است. این پروژه بر پایه اصول **شفافیت مطلق (Zero-Trust Openness)** بنا شده است:

### ۱. ارتباط ۱۰۰٪ مستقیم با سرور دانشگاه (Zero Middleware)
- تمامی درخواست‌های شبکه (`Login`, `Reservation`, `Credit`) **مستقیماً و منحصراً** میان تلفن همراه شما و دامنه رسمی دانشگاه (`https://jeton.bums.ac.ir`) ردوبدل می‌شوند.
- **هیچ سرور واسط، پروکسی، یا پایگاه داده ثالثی در این بین وجود ندارد.** ترافیک شبکه برنامه با ابزارهای تحلیل شبکه (مانند Wireshark یا HTTP Toolkit) توسط هر فرد متخصصی قابل بررسی و راستی‌آزمایی است.

### ۲. حفاظت از نام کاربری و کلمه عبور
- رمز عبور شما دقیقاً مشابه نسخه رسمی وب، با الگوریتم استاندارد رمزنگاری نامتقارن RSA و کلید عمومی خود سامانه دانشگاه رمز شده و به سرور فرستاده می‌شود.
- هیچ‌یک از اطلاعات ورود، نشست‌ها یا شماره‌های دانشجویی به جایی غیر از فضای امن محلی گوشی شما (حافظه رمزنگاری‌شده اندروید) منتقل نمی‌شود.

### ۳. کمترین سطح دسترسی ممکن (Minimal Permissions)
این برنامه **فقط و فقط یک دسترسی عادی** دارد:
- `android.permission.INTERNET` (تنها برای ارسال درخواست به وب‌سایت تغذیه).
- 🚫 **فاقد هرگونه دسترسی به:** دوربین، میکروفون، پیامک‌ها، مخاطبین، موقعیت مکانی (GPS)، حافظه خارجی، گالری یا فایل‌های شخصی!

### ۴. بیلد خودکار و امضای دیجیتال توسط GitHub Actions
- تمامی فایل‌های نصبی (APK) مستقیماً از روی سورس‌کد موجود در همین مخزن و توسط سیستم ابری رسمی **GitHub Actions** بیلد و امضا می‌شوند.
- فایل اثرانگشت دیجیتال (`SHA256SUMS.txt`) برای هر نسخه منتشر می‌شود تا مطمئن باشید فایلی که نصب می‌کنید دست‌کاری نشده است.

## 🛠️ معماری فنی و تکنولوژی‌ها

این پروژه با به‌کارگیری به‌روزترین ابزارها و استانداردهای توسعه نرم‌افزار اندروید پیاده‌سازی شده است:

- **زبان برنامه‌نویسی:** ۱۰۰٪ کاتلین (Kotlin 2.0+)
- **واسط کاربری (UI):** Jetpack Compose + Material 3 Design
- **معماری:** Clean Architecture همراه با الگوی MVVM (Model-View-ViewModel) و StateFlow
- **لایه شبکه:** Retrofit 2 + OkHttp 4 به همراه مدیریت پیشرفته کوکی‌ها (`JavaNetCookieJar`)
- **پارسر HTML / ASP.NET UpdatePanel:** کتابخانه `Jsoup` به همراه پارسر اختصاصی Delta پاسخ‌های سرور جهت هماهنگی کامل با چرخه `__VIEWSTATE` و WebForms
- **یکپارچه‌سازی مداوم (CI/CD):** پایپ‌لاین خودکار در GitHub Actions برای اجرای تست‌های واحد و کامپایل بیلد پایدار

## 🧪 اجرای تست‌ها و بیلد محلی

در صورتی که برنامه‌نویس هستید و می‌خواهید سورس را بررسی، بیلد یا تست کنید:

```bash
# ۱. کلون مخزن
git clone https://github.com/a-zangooei/kalinal_byms_client.git
cd kalinal_byms_client

# ۲. اجرای تست‌های واحد (شامل تست‌های کامل پکت‌های واقعی HAR)
./gradlew testDebugUnitTest

# ۳. تولید خروجی نصبی دیباگ
./gradlew assembleDebug
```
فایل APK کامپایل‌شده در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.
